# ADR-002：公开读取与受控上传

日期：2026-11-03。状态：用户明确修正后采纳；优先于早期内部成员读取方案。

市场目录和搜索向所有用户公开，包括未登录浏览。所有正常账号可以获得受应用与环境约束的安装会话。读取和使用不检查上传名单。

上传目前不向外开放，只允许运营配置的明确邮箱列表；未配置时上传关闭。上传资格既不是后台管理员角色，也不赋予审核发布、运行插件或业务资源权限。管理后台不能绕过同一上传校验。账号匹配使用当前权威账户的规范化邮箱，不能相信请求体传入的邮箱。

只有已审核并正式发布的版本进入公开目录；草稿、审核记录、在线密钥、账户令牌和私有数据不公开。安装仍校验摘要、TUF、兼容性、权限与隔离边界。匿名上下文不能准备安装、下载授权或运行插件，公开搜索也不能关闭已登录账户的活动插件。

旧成员表保留为未发布方案的迁移历史，运行代码不再读取。签名策略的受众标识统一为 market-readers。最小回归覆盖匿名浏览、登录安装、非上传者拒绝、上传者不自动获得管理权限、私有下载主体隔离、账户切换、撤销以及空目录初始化。
